Privacy Policy – Auto Web Clipper

Effective date: November 9, 2026

Auto Web Clipper is a local-first Chrome extension. Your saved notes stay in your browser. We do not sync your knowledge base to a notes cloud or require an account. Limited anonymous product usage analytics and optional feedback are described below.

What data the extension processes locally

  • User-selected website text (highlights)
  • Source page URL and title for that clip only (saved when you explicitly save a highlight; the extension does not collect browsing history)
  • Locally generated embeddings and note/category metadata
  • Study Mode session state (note IDs and assessment status only)

How local data is used

  • Save highlights as notes
  • Organize notes into categories using on-device processing
  • Power Study Mode active-recall review

Where note data is stored

Notes, categories, settings, and study sessions are stored locally in the user’s browser (IndexedDB / extension storage).

Anonymous usage analytics (always-on)

The extension sends anonymous product usage telemetry to PostHog Cloud (EU region) so we can understand how features are used (for example Study Mode actions, popup opens, note-save counts, and feedback-prompt actions). This is extension usage activity, not website content.

  • An anonymous installation identifier is created locally and reused for analytics (not an email, name, or Google account).
  • Events may include non-content metadata such as extension version and app surface (popup or tab).
  • There is no in-extension toggle to turn analytics off. Uninstalling the extension stops further client-side event sending.

Analytics does not include:

  • Note text / highlight content
  • Page titles or source URLs
  • Browsing history
  • Category names or IDs
  • Note IDs or study session queues
  • Free-text feedback comments

Optional feedback survey

After a small number of successful saves, the extension may show a short survey. If you submit it, the selected use case and optional comment are sent to an operator-hosted feedback backend (stored in that service’s database; the operator may receive a Telegram notification). Survey free-text is not sent to PostHog.

Data sharing and selling

  • We do not sell user data.
  • We do not use user data for advertising.
  • We do not share note content with third parties.
  • Anonymous usage events are processed by PostHog Cloud (EU). Feedback survey answers are processed on the operator feedback service.

Network access

The extension may download on-device embedding model assets (for example from Hugging Face / jsDelivr) so categorization can run locally in your browser. Note text is not uploaded to those hosts for processing or analytics. The extension may also contact PostHog (usage analytics) and the feedback API (only when you submit the survey). User note content is not uploaded for analytics or advertising.

Security

We use Chrome extension storage mechanisms and local processing where possible.

Your choices

  • You can delete notes/categories from the extension UI.
  • You can skip or dismiss the optional feedback survey.
  • You can remove the extension at any time to stop local processing and further client-side analytics sends.
