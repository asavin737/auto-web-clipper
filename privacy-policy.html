Privacy Policy – Auto Web Clipper

Effective date: April 8, 2026

Auto Web Clipper is a local-first Chrome extension. We do not operate a backend service for user notes.

What data the extension processes

  • User-selected website text (highlights)
  • Source page URL and title
  • Locally generated embeddings and note/category metadata

How data is used

  • Save highlights as notes
  • Organize notes into categories using on-device processing

Where data is stored

Data is stored locally in the user’s browser (IndexedDB / extension storage).

Data sharing and selling

  • We do not sell user data.
  • We do not use user data for advertising.
  • We do not share note content with third parties.

Network access

The extension may download machine-learning model assets (e.g., from Hugging Face/jsDelivr) required for local categorization. User note content is not sent to external analytics or ad services.

Security

We use Chrome extension storage mechanisms and local processing where possible.

Your choices

  • You can delete notes/categories from the extension UI.
  • You can remove the extension at any time to stop all processing.
